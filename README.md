# 주식 도구: 종목 추천 · 수익 계산기

Streamlit 웹앱 두 페이지로 구성됩니다.

| 페이지 | 내용 |
|---|---|
| 🎯 **종목 추천** (미국) | 유명한 매매법을 골라 S&P 500 / 나스닥 100 / 관심종목에서 조건에 맞는 종목을 찾고, 그 매매법의 과거 성과를 검증 |
| 📈 **수익 계산기 & 추세** (한국·미국) | 특정 날짜에 사서 팔았을 때의 손익(수수료·세금 반영)과 현재 추세 판정 |

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 종목 추천

### 사용 순서
1. 대상 종목: S&P 500, 나스닥 100, 둘 다, 또는 티커 직접 입력
2. 투자 기간: 단기(며칠) / 스윙(몇 주) / 중장기(몇 달). 매매법 기본값과 검증 보유 기간이 함께 바뀝니다.
3. 매매법 선택(여러 개 가능)과 결합 방식
   - **점수 합산**: 하나라도 신호가 있으면 후보. 신호 수, 그다음 평균 강도 순으로 정렬
   - **모두 만족 (AND)**: 고른 매매법 신호가 모두 있는 종목만
4. **추천 받기**. 처음 한 번은 시세를 받느라 S&P 500 기준 약 1분, 이후 6시간 동안 캐시

### 매매법

| 매매법 | 분류 | 신호 | 기본값 (단기 / 스윙 / 중장기) |
|---|---|---|---|
| 이동평균 골든크로스 | 추세추종 | 단기 이평선이 장기 이평선을 상향 돌파 | 5·20 / 20·60 / 50·200일 |
| 모멘텀 (상대강도) | 추세추종 | 기간 수익률 상위 N% (상태형) | 1개월 / 3개월(최근 1주 제외) / 12-1개월 |
| 터틀 트레이딩 | 추세추종 | N일 최고가 종가 돌파 | 20 / 55 / 120일 |
| 52주 신고가 근접 | 추세추종 | 52주 최고가 대비 N% 이내 + 거래량 증가 (상태형) | 3 / 5 / 8% |
| RSI 과매도 반등 | 역추세 | RSI가 기준선 아래에서 위로 회복 (200일선 위 필터) | RSI7·25 / RSI14·30 / RSI14·35 |
| 볼린저밴드 하단 반등 | 역추세 | 하단 밴드 밖에서 안으로 복귀 | 20일·2σ / 20일·2σ / 50일·2σ |
| MACD 상향 교차 | 역추세 | MACD가 시그널선 상향 교차 | 12·26·9 / 12·26·9 / 24·52·18 |
| 거래량 급증 양봉 | 수급 | 평소 대비 N배 거래량 + 상승 마감 | 3배 / 2.5배 / 2배 |

모든 수치는 화면의 "세부 설정"에서 바꿀 수 있습니다. 이벤트형 신호는 "최근 며칠 안의 신호"(기본 2 / 5 / 10거래일) 이내에 발생하면 유효로 봅니다.

### 과거 성과 검증
- 대상 종목 전체에서 추천 조건이 새로 충족된 날마다 **다음 날 시가 매수 → N거래일 뒤 종가 매도**를 가정
- 같은 종목 보유 중에 나온 신호는 무시, 편도 거래비용(기본 0.25%) 반영
- 비교 기준: 같은 종목·기간에서 아무 날 샀을 때 평균, 같은 날 SPY를 샀을 때 평균
- 한계: 현재 지수 구성 종목만 사용(생존 편향), 약 3년 데이터

## 코드 구조

```
app.py                  페이지 메뉴
views/recommend.py      종목 추천 화면
views/calculator.py     수익 계산기 화면
strategies/             매매법 (base: 공통 규격, trend / reversal / volume)
scanner.py              시세 일괄 수집 + 오늘의 추천
backtest.py             과거 성과 검증
data.py, analysis.py    수익 계산기용 데이터·계산
universes/*.csv         S&P 500, 나스닥 100 구성 종목
tools/update_universes.py  구성 종목 목록 갱신 (python tools/update_universes.py)
```

새 매매법은 `strategies/`에 `Strategy`를 상속한 클래스를 만들고 `strategies/__init__.py`의 `ALL_STRATEGIES`에 추가하면 화면에 자동으로 나타납니다.

## 주의
- 추천은 정해진 규칙에 맞는 종목을 걸러낸 결과이며 투자 권유가 아닙니다.
- 수익 계산기의 수수료·세율 기본값은 예시이니 실제 값으로 바꿔 쓰세요. 환율, 양도소득세, 배당은 반영하지 않습니다.
