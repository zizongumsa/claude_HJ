# 주식 수익 계산기 & 추세 분석

한국·미국 주식의 일봉 시세를 받아 **"이날 사서 이날 팔았다면 얼마를 벌었을까"**를 계산하고,
기술적 지표로 **현재 추세**를 요약해 주는 Streamlit 웹앱입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다.

## 종목 입력

| 시장 | 입력 예 | 데이터 소스 (순서대로 시도) |
|---|---|---|
| 한국 | `005930`, `삼성전자`, `카카오` | FinanceDataReader(네이버) → yfinance(.KS/.KQ) |
| 미국 | `AAPL`, `tsla` | yfinance → FinanceDataReader |

종목명은 네이버 종목 검색으로 코드로 바꾸고, 실패하면 KRX 종목 목록에서 찾습니다.

## 기능

- **매매 시뮬레이션**: 매수·매도일, 시가/종가 기준, 투자금 또는 수량 입력
  - 휴장일을 고르면 매수는 다음 거래일, 매도는 직전 거래일로 자동 조정
  - 수수료와 매도 거래세를 차감한 순손익, 수익률, 연환산 수익률
  - 기간 내 사후적 최적 매수·매도 시점 (참고용)
- **추세 판정**: 강한 상승 / 상승 / 횡보 / 하락 / 강한 하락 (점수 −100 ~ +100)
  - 최근 N거래일 로그가격 회귀 기울기 × R² (±35)
  - 이동평균 정배열/역배열 (±25), 20일선 위치 (±10)
  - 최근 10거래일 내 골든·데드크로스 (±10), MACD (±10)
  - RSI는 점수에 넣지 않고 과매수·과매도 경고로만 표시
- **차트**: 캔들 + 이동평균/볼린저밴드, 매수·매도 지점 표시, 거래량, RSI, MACD

## 파일 구성

- `data.py`: 시세 로더 (시장 판별, 종목명→코드 변환, 소스 대체 처리)
- `analysis.py`: 손익 계산(`calc_trade`), 지표(`add_indicators`), 추세 요약(`summarize_trend`)
- `app.py`: Streamlit 화면

## 주의

- 기본 수수료·세율(한국: 수수료 0.015%, 매도 거래세 0.20% / 미국: 수수료 0.25%)은 예시입니다.
  사이드바의 "수수료 · 세금 설정"에서 실제 값으로 바꾸세요.
- 환율, 양도소득세, 배당은 반영하지 않습니다. 액면분할 등이 있었던 종목은 소스에 따라 수정주가 여부가 다를 수 있습니다.
- 과거 데이터 기반 시뮬레이션이며 투자 권유가 아닙니다.
